# Dating App Admin Panel

This is a React-based admin panel for managing the Dating App.

## Features
- **Dashboard**: Overview of app statistics.
- **Report Management**: View and resolve user reports.
- **User Moderation**: Ban/Unban users based on reports.
- **Media Review**: Inspect reported media content.

## Setup
1. `npm install`
2. Configure `firebase-config.js` with your project credentials.
3. `npm start`
